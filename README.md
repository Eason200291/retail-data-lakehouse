# Retail Data Lakehouse on Databricks

## Project Overview

This project demonstrates an end-to-end Data Engineering pipeline built on Databricks using PySpark and Delta Lake.

The project follows the Medallion Architecture (Bronze, Silver, Gold) to transform raw retail transaction data into analytics-ready datasets.

## Tech Stack

- Databricks
- PySpark
- Spark SQL
- Delta Lake
- Python
- GitHub
